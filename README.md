# haru-characters

A shared library of characters for [haru-kit](https://github.com/yungalgo/haru-kit). haru-kit runs [Haru-4B](https://huggingface.co/higurashi-ai/Haru-4B), an open voice model that listens and talks at the same time, on a Mac, an NVIDIA GPU, or a cloud GPU. Haru-4B comes with almost no characters and no voices, so this is a place to share characters and to try the characters of other people.

A character is a person for Haru to be: a short description (the "card") and a voice, for each language that it speaks.

## Use a character

In haru-kit, click **Browse characters**, then **Add to my library**.

## Share your character

1. In haru-kit, make your character. Give each language a voice in that language, and fill in **Author**.
2. Export it: **Export the character (.haru)**.
3. Here on GitHub, open the folder [`submissions`](submissions), click **Add file → Upload files**, and upload the `.haru` file. GitHub opens a pull request for you.
4. A check comments on your pull request. When the pull request is merged, your character shows in **Browse characters** a minute or two later.

Use your own voice, or a voice that you may share.

To change your character, export it again and upload the new file the same way. Keep the same name, so that it replaces the old one.
